## Descripción
This is a really weird text file [TXT](https://jupiter.challenges.picoctf.org/static/e7e5d188621ee705ceeb0452525412ef/flag.txt)? Can you find the flag?
## Solución
1. Download the file.
2. Describe the file with ```file flag.txt```. We discover it is a png file.
3. Then we rename the file to "flag.png" and we open the file like any other image and we can retrieve the flag: ```picoCTF{now_you_know_about_extensions}```
