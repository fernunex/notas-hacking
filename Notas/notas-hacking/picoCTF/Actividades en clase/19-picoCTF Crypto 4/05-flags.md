## Description
What do the [flags](https://jupiter.challenges.picoctf.org/static/fbeb5f9040d62b18878d199cdda2d253/flag.png) mean?
## Solution
1. Each flag corresponds to a letter assigned to a flag using the International Maritime Signal Flags. ![](../../../images/Pasted%20image%2020251031151320.png)

2. Substitute each flag for a letter: ```PICOCTF{F1AG5AND5TUFF}```
