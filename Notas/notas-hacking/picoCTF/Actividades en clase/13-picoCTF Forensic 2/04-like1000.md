## Description
This [.tar file](https://jupiter.challenges.picoctf.org/static/52084b5ad360b25f9af83933114324e0/1000.tar) got tarred a lot.
## Solution
1. Download the file.
2. Unpack the file with `7z x` using a for loop:
	`for i in {1000..1}; do 7z x -y $i.tar; done`
3. Open the flag.png and the flag is: `picoCTF{l0t5_0f_TAR5}`

## Additional notes
Using a script to unpack:
```
import tarfile

for i in range(1000, 0, -1):
    arch = "{}.tar".format(i);
    print(arch)
    tar = tarfile.open(arch)
    tar.extractall()
    tar.close()
```
